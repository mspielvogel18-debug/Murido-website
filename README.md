# Murido — website

Static marketing and legal site for the Murido iOS app.
Plain HTML, no framework, no build step. Served by GitHub Pages from `main`.

- `index.html` — landing
- `privacy.html` — privacy policy (App Store requires a reachable URL)
- `terms.html` — terms of use
- `support.html` — support / data deletion
